## Features

- Dark minimal cover page (`S24HV`)
- Product catalog with pagination
- Sort by name / price / stock
- Product detail page with image gallery
- Responsive layout
- Deployed on GitHub Pages

- TypeScript
- Vite 6

- SCSS
